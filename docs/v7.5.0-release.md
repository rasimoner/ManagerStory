# ManagerStory V7.5.0

Release: 2026-10-15, by user decision after reviewing the iPhone preview of `dev/v7.5.0` ("Harika oldu bunu yayına alalım"). Further improvements continue in later versions.

## What is new

- New 3D match view (default when 3D is selected): stylized footballers on ManagerStory's own skeleton, CC0 locomotion (walk, jog, sprint), hand-keyed pass/shot/feint/tackle/goalkeeper/throw-in actions, toon stadium with animated crowd in club colours, automatic broadcast camera with close-ups and slow motion for duels and shots.
- The view plays the real MatchEngine events. The existing presentation clock follows the view and the next engine minute waits for it: one engine, one clock; pause, speed, half time, injuries/substitutions and the single result application are unchanged.
- Ball stays in play unless the engine puts it out; throw-ins, corners and goal kicks restart from the engine's spot.
- Fullscreen broadcast mode (⤢): score bug and clock, commentary, ball carrier, radar, camera choice, speed, pause and Müdahale; leaves by itself at half time, injury stops and full time.
- Everything shipped is free and open (`docs/open-assets.md`); no Mixamo assets.
- The previous 3D renderer remains reachable with `?eski3d=1`.

Version labels, script cache URLs, manifest and offline cache key are 7.5.0. Career saves keep their data (version stamp only).

## Checks

- Release gate (same set as V7.4.3): `tests/managerstory.test.cjs`, `match3d-carry-facing`, `match3d-gait-continuity`, `match3d-approved-player` — 62/62.
- Browser: full career match in fullscreen, 473 events, same result as the engine, 0 errors, 0 stalls; 2D/3D, tabs, pause and reload mid-match.
- Full historical suite is not green (known test debt; the same failures exist on V7.4.3). Publication uses `.github/workflows/publish-reviewed-v750.yml`, which deploys only the reviewed `dist` tree after the gate above.

## Known limits

Hand-keyed football actions (no mocap yet), no headers or slide tackles, engine events per minute can make players shift together at minute boundaries, some engine `block` events are keeper saves.
