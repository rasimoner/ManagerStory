# ManagerStory V7.9.0

Release: 2026-10-19, by user decision ("sen main le birleştir bu görevlerden sonra"). Details in `docs/v7.9.0-progress.md`.

## What is new

- Special moves for special players, only where they fit on the pitch: step-over, nutmeg, elastico, no-look pass, Cruyff turn, La Croqueta, Marseille turn, flair nutmeg, step-over pass, rainbow flick, sombrero, keep-it-up, backheel pass, rabona, killing a falling ball, Panenka, chip over the keeper, bicycle kick, Bergkamp's turn. Each player's stars and moves are shown on his card.
- Star replay: a special move is shown again at once, slowly, from a close camera.
- A keeper never dribbles the ball upfield; he plays it out with a pass.
- Temporary "Yıldız anı dene" buttons in the speed panel (to be removed later, by user decision).

Version labels, script cache URLs, manifest and offline cache key are 7.9.0. Career saves keep their data.
