# ManagerStory V7.8.2 — development

Branch `dev/v7.8.2`, started 2026-10-18 from `main` (V7.8.1).

## Players drawn white

Found while comparing a "star moment" prototype the user had made with ChatGPT (its package fixed this for itself): in the 3D view about half the players had no skin or hair colour and were drawn white (face, arms, hair; 50 of 80 player keys). Each player's look comes from a 32-bit hash of his key; the skin, hair colour and build were picked with a signed shift (`h >> 8`), which turns a hash above 2^31 negative, so the list index was negative and the colour undefined (Three.js then uses white). The shifts are unsigned now (`>>>`); every player gets a skin tone, a hair colour and a build. Checked on a live match in the browser (before/after screenshots), 0 page errors.
